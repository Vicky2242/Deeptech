HTML

HTML stands for HyperText Markup Language.

It structures web content using elements.

<h1>Hello World</h1>
  • Headings
  • Paragraphs
  • Lists
CSS

CSS styles the HTML structure.

You can change colors, layouts, and fonts.

body { background-color: lightblue; }
  • Selectors
  • Properties
  • Values
JavaScript

JavaScript adds interactivity to web pages.

It runs in the browser.

console.log("Hello World");
  • Variables
  • Functions
  • Events
Responsive Design

Responsive design makes websites usable on all devices.

Media queries help adjust layouts.

@media (max-width: 600px) { body { font-size: 14px; } }
  • Fluid grids
  • Flexible images
  • Media queries
Accessibility

Accessibility ensures websites are usable by everyone.

Use semantic HTML and ARIA attributes.

<button aria-label="Close">X</button>
  • Alt text
  • Keyboard navigation
  • Screen readers
